# 🚀 منصة X (Social Real-Time Cloud App)

تطبيق تواصل اجتماعي فائق السرعة مبني بمحاكاة دقيقة لتصميم وهوية منصة **X (تويتر سابقاً)** بطابع داكن حديث، يدعم النشر، التحديثات اللحظية (Real-Time)، رفع وتحميل الصور والوسائط، وقاعدة بيانات سحابية مجانية ودائمة بدون توقف.

---

## 🌟 أبرز مميزات التطبيق

### 1. الهيكل والتصميم البصري (X Theme & Layout)
- **الهوية البصرية:** خلفية سوداء خالصة (`#000000`) مع حدود رفيعة جداً بلون رمادي داكن ناعم (`#2f3336`)، وأزرار مميزة باللون الأزرق المشرق (`#1d9bf0`).
- **نظام الأعمدة الثلاثة:**
  1. **العمود الأيمن (Sidebar):** شعار X، الرئيسية، استكشاف، الإشعارات مع عداد التنبيهات، الرسائل، العلامات المرجعية، الملف الشخصي، وزر النشر البارز وبطاقة المستخدم.
  2. **العمود الأوسط (Main Feed):** شريط علوي مثبت مع تبويبين (**لك / For You** و **متابَعون / Following**)، صندوق النشر الفوري، وقائمة المنشورات المتتالية.
  3. **العمود الأيسر (Trends & Search):** حقل بحث لحظي سريع، بطاقة **ماذا يحدث الآن (What's happening)** مع عدادات التغريدات، وبطاقة **اقتراحات المتابعة (Who to follow)**.

### 2. النشر والوسائط (Media & Publishing)
- **صندوق النشر (Post Composer):** كتابة حرة مع تلوين الهاشتاجات (`#تطوير`) والروابط التلقائي.
- **رفع الصور والملفات:** إمكانية اختيار الصور أو المستندات مع مؤشر تقدم الرفع (Progress Bar).
- **معاينة فورية:** ظهور معاينة الصورة مع زر إزالة بنقرة واحدة قبل الإرسال.
- **عرض وتحميل الوسائط (Lightbox Modal):**
  - النقر على أي صورة يفتح عارض شاشة كاملة (Lightbox) بخلفية شبه شفافة وأدوات تكبير/تصغير.
  - **زر تنزيل فوري:** زر مخصص في العارض وعلى المنشور لتحميل الصورة أو المستند مباشرة إلى جهاز المستخدم بجودتها الأصلية!

### 3. التحديثات اللحظية (Real-Time Cloud)
- **مزامنة فورية بدون F5:** عند قيام أي مستخدم بالنشر أو التفاعل، يظهر التحديث فورياً لكل المستخدمين المتصلين في نفس اللحظة عبر WebSockets.
- **شريط التنبيه اللحظي (New Posts Banner):** عند وصول منشورات جديدة في الخلفية يظهر زر عائم: `إظهار X منشورات جديدة 🚀` يقوم بالتمرير للأعلى بسلاسة.
- **العدادات الحية:** تحديث فوري لأرقام الإعجابات، الردود، وإعادة النشر.

### 4. التفاعلات الاجتماعية
- **الردود (Replies):** نافذة منبثقة تفاعلية تعرض سلسلة الردود السابقة مع خط الربط الرأسي كما في X وصندوق الرد المباشر.
- **إعادة النشر (Repost):** زيادة العداد فوراً وتغير الأيقونة للون الأخضر (`#00ba7c`).
- **الإعجاب (Like):** تفاعل حركي ممتع مع تأثير القلوب والكونفيتي وتلوين القلب بالأحمر (`#f91880`).
- **العلامات المرجعية (Bookmark):** حفظ المنشورات للرجوع إليها.
- **المشاركة (Share):** نسخ الرابط المباشر إلى الحافظة فوراً.
- **خيارات المنشور:** إمكانية حذف المنشور لصاحبه.

### 5. قاعدة البيانات السحابية المجانية (Google Firebase)
- **دائمة 24/7:** لا تنام ولا تتوقف أبداً (Free Spark Plan).
- **مجانية 100% مدى الحياة:** تشمل 50,000 عملية قراءة و 20,000 عملية كتابة يومياً و 5GB مساحة وسائط مجانية.
- **نظام هجين ذكي:** يعمل التطبيق مباشرة بوضع تجريبي ومزامنة Cross-Tab، ويمكن ربط مفاتيح Firebase بنقرة واحدة من داخل التطبيق (عبر نافذة "الربط السحابي") أو عبر ملف `.env`.

### 6. نظام التحديثات التلقائية (Auto-Updates Architecture via GitHub & PWA)
- **تطبيق ويب تقدمي (PWA):** مدعوم بـ Service Worker يفحص وجود أي إصدار جديد فور الاتصال بالإنترنت.
- **إشعار التحديث الفوري:** عند نشر أي تحديث، يظهر إشعار عائم في التطبيق: `تحديث جديد متوفر للتطبيق! [تحديث الآن]` وبنقرة واحدة يتم تطبيق التحديث دون فقدان أي بيانات.
- **GitHub Actions جاهز:** ملف `.github/workflows/deploy.yml` موجود وجاهز؛ بمجرد عمل `git push` إلى GitHub، يتم بناء التطبيق ونشره تلقائياً ويصل التحديث لجميع المستخدمين فوراً.

## 🛠️ خطوات التشغيل المحلي

```bash
# 1. الدخول لمجلد المشروع
cd x-social

# 2. تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:5173`

---

## ☁️ ربط قاعدة بيانات Firebase المجانية في دقيقة واحدة

1. ادخل إلى [Firebase Console](https://console.firebase.google.com) وأنشئ مشروعاً جديداً.
2. من القائمة الجانبية:
   - فعّل **Firestore Database** واضغط على "Create Database".
   - فعّل **Storage** واضغط على "Get Started".
3. انسخ إعدادات المشروع (Project Settings ⚙️ -> Web App `</>`).
4. افتح التطبيق واضغط على زر **الربط السحابي** في الشريط الجانبي والصق الكود مباشرة، وسيتم الاتصال فوراً!
