## 🌟 البنية السحابية الموحدة (Cloudflare Workers + D1)

تم توحيد المنصة بالكامل في مكان واحد فائق السرعة: **Cloudflare**:
1. **واجهة المستخدم (Frontend SPA):** مستضافة على Cloudflare Workers Static Assets وتعمل على شبكة الحافة (Edge Network) الموزعة في أكثر من 330 مدينة حول العالم.
2. **واجهة برمجة التطبيقات (Edge REST API):** تعمل بنظام Serverless على خوادم Cloudflare Workers مع دعم 0ms استجابة لحظية.
3. **قاعدة البيانات السحابية (Cloudflare D1):** قاعدة بيانات SQL موزعة عالمياً (`gxe-db`) بزمن استعلام فائق الصغر (< 1ms).

## ⚡ المصطلحات والميزات الخاصة بمنصة GXE

* **الهري:** خلاصة المنشورات العامة لجميع المستخدمين (Global Feed).
* **هارية:** المنشور الفردي أو المحتوى المنشور.
* **افتي ⚡:** زر النشر الفوري مع دعم الوسائط والصور والهاشتاجات.
* **الهاري:** الردود والتعليقات على أي هارية.
* **الدردشة الخاصة (DMs):** محادثات مباشرة فورية بين الأعضاء في الوقت الفعلي.
* **نظام التفاعل اللحظي (0ms Optimistic UI):** يظهر أي تفاعل (نشر، تعليق، إعجاب، حذف) على شاشة المستخدم في 0ms فوراً مع مزامنة خلفية في قاعدة بيانات Cloudflare D1.
